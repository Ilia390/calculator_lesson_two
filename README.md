# Семейный бюджет

Веб-приложение для учёта семейных финансов: приветственная страница и калькулятор доходов, расходов и накоплений.

Данные хранятся только в браузере (`localStorage`). Сервер и регистрация не нужны.

## Возможности

- приветственный лендинг с переходом к калькулятору
- добавление доходов и расходов по категориям
- остаток, доля накоплений и финансовый анализ
- цель накоплений и диаграмма расходов
- экспорт и импорт JSON
- светлая и тёмная тема (кнопка в правом нижнем углу)

## Как открыть

1. Скачайте или клонируйте проект.
2. Откройте файл `index.html` в браузере.
3. Нажмите **Начать вести бюджет**, чтобы перейти к калькулятору.

Либо запустите локальный сервер из папки проекта:

```bash
python -m http.server 8080
```

Затем откройте http://localhost:8080/

## Структура

```
index.html                 приветственная страница
calculator.html            калькулятор бюджета
css/styles.css             общие стили и тёмная тема
js/theme.js                переключение темы
js/calculator.js           логика учёта
Калькулятор бюджета.html   переход на calculator.html
```

## Тема и данные

Выбранная тема сохраняется в `familyBudgetTheme`.
Операции — в `familyBudgetTransactions`, цель — в `familyBudgetGoal`.
